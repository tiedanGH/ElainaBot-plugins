# 随机工具

在本地沙箱内运行的随机数 / 骰子 / 智能算式插件，指令前缀 `/rd` 或 `#rd`。

## 指令

| 指令                          | 说明                                                                              |
|-----------------------------|---------------------------------------------------------------------------------|
| `/rd`                       | 1~100 随机整数                                                                      |
| `/rd <算式>`                  | 智能算式（≥3 字符，仅 ASCII），支持 `XdY` 骰子与 math / random 函数，例：`d20+3`、`3d6*2`、`sin(pi/2)` |
| `/rd c <n> <元素列表>`          | 抽取 n 个不重复的元素                                                                    |
| `/rd r <n> <元素列表>`          | 抽取 n 个可重复的元素                                                                    |
| `/rd rn <n> <元素列表>`         | 抽取 n 个可重复的元素（合并计数）                                                              |
| `/rd i [下界] <上界>`           | 随机 1 个整数                                                                        |
| `/rd ic <n> [下界] <上界>`      | 随机 n 个不重复的整数                                                                    |
| `/rd ir <n> [下界] <上界>`      | 随机 n 个可重复的整数                                                                    |
| `/rd f <n> <下界> <上界> [小数位]` | 随机 n 个浮点数，默认 3 位小数                                                              |
| `/rd help`、`/rd 帮助`         | 指令帮助                                                                            |
| `/rd info`、`/rd 信息`         | 插件简介                                                                            |

## 限制

- 数值范围 ±10^20，个数 `n` 上限 20（`rn` 为 1000000）。
- 骰子 `XdY` 的 x、y 取值 1~1000000，`d` 不能连用。
- 算式仅允许可打印 ASCII 字符，单次计算超时 1.5 秒。
- 结果超过 300 字符时转科学计数或截断；算式与结果整体超过 500 字符时改用求和后的简化式。

## 输出安全

机器人回复只包含硬编码模板、机器生成的随机数和占位符，**不回显任何用户输入**：

- `c` / `r` / `rn` 的元素统一替换为 `[元素1]`、`[元素2]` … 后再抽取，输出不出现原始元素文本。
- 智能算式不显示原算式（仅显示骰子展开与最终数字结果），错误提示全部为固定文案。

## 依赖

智能算式依赖 `RestrictedPython`（见 `requirements.txt`，框架会自动安装）。未安装时插件仍可加载，仅智能算式不可用，加载时会输出一条警告日志。
